# Football Analytics Dashboard

An interactive Excel dashboard for analyzing football team and player performance, built from raw match data using pivot tables, slicers, and dynamic visualizations.

## Overview

This project turns raw football match statistics into an interactive dashboard for exploring team performance, goal-scoring trends, player contributions, and league standings. It was built to demonstrate practical data analysis and dashboard design skills using Microsoft Excel.

## Objective

- Analyze football match data efficiently and accurately
- Build an interactive dashboard that supports quick, data-driven decisions
- Visualize team and player performance metrics clearly
- Apply core data analysis and dashboard design principles in Excel

## Tools Used

- **Microsoft Excel** — Pivot Tables, Pivot Charts, Slicers, Conditional Formatting
- Data cleaning and preparation
- Dashboard design and layout

## Data Preparation

1. Imported and consolidated raw match data
2. Removed duplicate records
3. Handled missing values
4. Standardized team and player names for consistency
5. Created calculated fields (e.g., goals per match, per-position aggregates)
6. Validated totals and cross-checked statistics for accuracy

## Dashboard Features

**KPIs**
- Total Matches
- Total Goals
- Average Goals per Match
- Number of Teams
- Number of Players

**Interactive Filters (Slicers)**
- Team
- Position
- Competition/League
- Player

**Visualizations**
- Goals by Team
- Goals by Position
- Team Performance Comparison
- Goal Distribution
- Dynamic KPI Cards
